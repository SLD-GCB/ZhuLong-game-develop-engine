# 宿主

`宿主/` 是**用**这台机器的程序。它们不属于机器 —— 一条规矩：宿主不组装机器、不跑循环，
只实现 `Platform` 并把它交出去，剩下的由 `内核/system` 驱动。

| 程序 | 是什么 | 关键参数 |
|---|---|---|
| `render_scene` | 最小的一个：读一个 `.scene`，渲染，存 BMP | `--scene FILE` `--vulkan` |
| `gugong` | 故宫：一个设计过的 3D 场景（院子 / 室内两个视角） | `--inside` `--out FILE` |
| `viewer` | 开一个窗口，把画面显示出来 | `--scene FILE` `--frames N` `--headless` `--vulkan` |
| `mix_scene` | 把场景的声音混成 WAV，不需要窗口也不需要声卡 | `--scene FILE` `--seconds F` `--device` |
| `xiangqi` | **象棋**：完整可玩的游戏（规则、AI、程序化棋子、按键） | `--demo` `--selfplay` `--probe` `--write FILE` `--headless` `--frames N` |
| `modeler` | **建模器**：把一份模型画出来，`1`/`2` 选面选点，`E` 挤出，`D` 细分（Catmull-Clark），`B` 把选中的角切掉，`C` 把选中那个面的一圈边标成硬边 / 取消（细分时它们不跟着变圆），`X` 删掉选中的面（留一个洞），`Z` 撤销，`S` 存回原处、`O` 从原处再读一遍；编辑器的「上色」给选中的面换一种颜色、「贴图…」给它挂一张 BMP（**逐面材质：按材质拆成几个节点画**）。左键选一个拖着走（**按着 Shift 吸附到 0.05**），右键转、中键平移、滚轮缩。**导入**别人的网格文件（OBJ）从编辑器的「导入…」来 —— 它有损，所以会把账报到控制台。**只在编辑器里跑**（见 [05-编码器](05-编码器.md) 的「3D 建模」那一页），而且**包里有成品**：编辑器起的是 `建模器/建模器.exe`，不是编它。**它不收 `--model`** —— 路径只能从管子里来，理由见那里 | `--width N` `--height N` `--shadow N` |
| `audio_device/` | 声卡对 `audio::Sink` 的实现（WASAPI 共享模式） | 一个库，被别的程序链 |

## 六条命令

两个构建树里的位置不同，命令一样。**Visual Studio 那条**在 `build\宿主\Release\`，
**Zig 那条**（`打包.py` 用的）在 `build-zig\宿主\`：

```bat
:: 一个场景，一张图
build\宿主\Release\zlong_render_scene.exe --scene 宿主\scenes\demo.scene

:: 故宫的室外和室内
build\宿主\Release\zlong_gugong.exe            --out 截图\故宫-室外.bmp
build\宿主\Release\zlong_gugong.exe --inside   --out 截图\故宫-室内.bmp

:: 开着窗口看（Esc 或关窗退出）
build\宿主\Release\zlong_viewer.exe --scene 宿主\scenes\demo.scene --vulkan

:: 声音混到文件，顺便验证混音器
build\宿主\Release\zlong_mix_scene.exe --scene 宿主\scenes\demo.scene --seconds 1.0

:: 象棋（要玩就按键：方向键移动、回车落子、Esc 取消、R 重开、C 交给电脑）
build\宿主\Release\zlong_xiangqi.exe

:: 建模器 —— 它没有自己的窗口，所以这一条**必须在编辑器里发**（或者自己设 ZL_EDITOR_HOST=1），
:: 否则它只会告诉你这件事。编辑器里打开 宿主\modeler\main.cpp 按 F5 就是了。
build-zig\宿主\zlong_modeler.exe --width 800 --height 500
```

编辑器里**不用**记这些路径：打开对应的 `main.cpp` 按 F5 就行，参数写工具栏那个框。
见 [05-编码器](05-编码器.md)。

> **这六个程序不在发行包里。** 包里的东西是：编辑器、**建模器**、C++ 内核（`ziglib` 里那 15 个 `.a`）、
> 内核的头、两套解释器。宿主是"用内核写的程序"，不是内核 —— 象棋、故宫和建模器特别说明了不带。
> 想跑它们，从源码树这份来。
>
> **包里跟宿主有关的两样，只有两样**：`include/editor_host.h`（纯头，让程序出现在面板里）和
> `运行环境/ziglib/宿主/libzlong_host_audio.a`（声卡）。见
> [08-从包里调组件](08-从包里调组件.md) 第七节。
>
> 从包的角度看，一个宿主程序是这样的：**跟着它同一文件夹的 `.cpp` 一起编，链 `include/` 和
> `ziglib/`**。`宿主/xiangqi/main.cpp` 旁边有五个 `.cpp`，所以它编得动；你要是只把 `main.cpp`
> 单独拷出来，那就缺 5 个符号源。

## 怎么写一个自己的

最短的完整宿主（这是 `编码器/examples/spin_scene.cpp` 的骨架）：

```cpp
#include "zlong/system/system.h"

class MyHost final : public zlong::system::Platform {
public:
    bool Pump() override { return true; }                     // false = 该收工了
    void Present(const std::uint8_t* rgba, std::uint32_t pitch,
                 std::uint32_t width, std::uint32_t height) override { /* 一帧画好了 */ }
    void OnFrame(zlong::engine::Scene& scene, double seconds) override { /* 一帧的动画 */ }
    void OnMix(zlong::engine::Scene& scene, double seconds) override { /* 一块的声音 */ }
};

int main() {
    zlong::system::System::Config config;
    config.width = 1024; config.height = 640;
    config.dram_bytes  = 512ull * 1024 * 1024;
    config.arena_bytes =  64ull * 1024 * 1024;     // 画面越大，arena 越大
    config.vulkan = true;
    config.frame_interval_ms = 1000.0 / 60.0;      // 0 = 全速

    zlong::system::System machine(config);
    if (!machine.ok()) { /* machine.error() 说为什么 */ return 1; }

    zlong::engine::Scene scene;
    // ……往 scene 里加 mesh / material / node / light……

    MyHost host;
    machine.set_platform(&host);
    if (!machine.Load(scene)) { /* scene 装不下 arena，或者哪里不对 */ return 1; }
    machine.Run(-1);                               // -1 = 一直跑
}
```

**四个回调都可以不写** —— `Platform` 每一个都有默认实现（什么都不做）。一个 headless 的运行一个
都不用写，`machine.Run(300)` 直接跑。

`machine.Load()` 之后 `machine.scene()` 拿到的就是你交进去的那个场景；在 `OnFrame` 里改它，
下一帧就照改完的画。

### 编辑器要你当窗口时

如果想让自己的程序**在编辑器的右边面板里显示、并且从那里收键盘**，加两行：

```cpp
#include "editor_host.h"                    // 在 宿主/ 下

class MyHost final : public zlong::system::Platform {
    std::unique_ptr<zlong::editor::Host> editor_;
public:
    MyHost() {
        if (zlong::editor::requested()) { editor_ = std::make_unique<zlong::editor::Host>(); }
    }
    bool Pump() override {
        if (editor_ == nullptr) return true;
        if (!editor_->Pump()) return false;                 // 编辑器走了
        keys_ = editor_->TakePresses();                     // 虚拟键码，和窗口给的一样
        return true;
    }
    void Present(const std::uint8_t* rgba, std::uint32_t pitch,
                 std::uint32_t w, std::uint32_t h) override {
        if (editor_ != nullptr) editor_->Present(rgba, pitch, w, h);
    }
};
```

要点：

- 编辑器会给它启动的**每个** C++ 程序设 `ZL_EDITOR_HOST=1`。不看这个变量的程序一切照旧 ——
  所以同一个程序既能独立跑，也能在编辑器里跑，不需要两份。
- 按键是**虚拟键码**（`VK_LEFT`=37、`VK_RETURN`=13…），和窗口过程当初塞进队列里的整数一样，
  所以已有的键映射一个字不用改。
- 帧是**不阻塞**发的：一帧一槽，编辑器跟不上就丢掉旧的，只计数不排队。程序自己的速度不受影响。
- **鼠标也在那儿**：`pointer()` 是最新的位置（画面自己的像素），`TakeClicks()` 是按下抬起的动作
  （排队，不合并），`TakeWheel()` 是滚轮格数（累加）。`宿主/modeler/main.cpp` 用了它们 ——
  右键拖着转、中键拖着平移、滚轮缩、左键拾取。见 [05-编码器](05-编码器.md) 的鼠标一节。

`宿主/xiangqi/main.cpp` 是一个完整的例子：它有自己的 `Window` 类（GDI + 键盘），
`OpenWindow()` 里二选一，两边的其余代码完全一样。

## 关于窗口和分辨率的一个坑

`宿主/xiangqi` 和 `宿主/viewer` 用 GDI 画：机器渲染到内存，`Present` 拿到的 RGBA 转成 BGRA 再
`StretchDIBits` 到窗口的 DC 上。**没有 DirectX、没有交换链** —— 因为软件渲染器也得能显示。

这些程序是 **DPI 不感知**的。在一台 125% 缩放的机器上，它以为自己开的是 1024×640，Windows 在屏幕上
把它拉成 1280×800。读它的窗口 DC 拿到的是**没被拉的**那份像素 —— 这一点在
[05-编码器](05-编码器.md) 的镜像一节还会出现。

## 挑一个模型

想在编辑器里从零写一个新宿主，**从模板开始**：文件 → 从模板新建 → 「C++ 主机程序」。它给的就是
上面那份骨架加上 `editor_host.h` 的接线，按 F5 就能跑。
