# 3D 建模器

> *「对着建模的那块画布，就是游戏将来显示用的那一个，不是它的预览。」*

编辑器「3D 建模」那一页起起来的那个工具。它**没有自己的窗口** —— 画面走面板，鼠标键盘也走面板。
你在里面捏出来的东西是一份 `.model` 文件，能被游戏直接读进去摆进场景。

---

## 一、怎么进去

编辑器顶上切到「3D 建模」那一页。**进去的时候它顺手把建模器起起来**（如果还没有东西在跑），
所以进去就是能用的；要是已经有东西在跑，它不抢 —— 想换就按「开始建模」。

> 建模器**只在编辑器里跑**。它没有自己的窗口，也不收 `--model` 之类的路径参数 ——
> 路径只能从管子里来，因为 **Windows 的命令行传不了中文路径**（见 [01-构建](01-构建.md)）。

## 二、手：鼠标

| 动作 | 干什么 |
|---|---|
| **左键拖空处**（或**右键拖**） | **转场景**（上下左右） |
| **Shift + 左键拖空处**（或**中键拖**） | 平移 |
| **滚轮** | 推近 / 拉远。**选中了一个对象（对象模式）时，滚轮改成缩它** —— 要缩画面就按着 `Shift` 滚，或者点一下空处取消选中 |
| **Shift + 滚轮** | 始终缩**画面**（不看选没选中） |
| **左键点一下** | 选一个东西（面 / 点 / 对象，看当前是哪个模式） |
| **左键按住拖**（点在东西上） | 把它拖着走。**拖动中按 `X` / `Y` / `Z` 把这一拖锁到那根世界轴上**（上下、左右、前后就都能精确挪了），再按同一根解开 |
| **Shift + 拖**（点在东西上） | 吸附到 **0.05** 的格子上 |

### Shift 吸附的规矩：吸"落到哪儿"，不是"走了多远"

取整位移的话，一个本来就偏在格与格之间的东西会**永远偏着** —— 而"把它摆到格上"正是按 Shift 的
理由。所以取整的是**选择的中点落点**，然后反推位移：形状原样保留，中点落在格上。

0.05 是挑的：单位大的图元正好是它的整数倍，挤出那 0.25 也是。

## 三、键盘和面板按钮

**面板上那些按钮不自己实现任何东西 —— 它们只替用户敲一下键。** 所以这一页和"打开一个 `.cpp`
按 F5、用键盘操作它"是同一条路，只是排得顺手一点。

| 键 | 按钮 | 干什么 |
|---|---|---|
| `1` | 选面 | 切到**选面**模式 |
| `2` | 选点 | 切到**选点**模式 |
| `3` | 选对象 | 切到**选对象**模式：点一下**选中一整个图形**（一个对象），按住左键**整块拖** |
| `E` | 挤出 | 把选中的面沿它自己的法线挤出一层（`0.25`） |
| `D` | 细分 | Catmull-Clark 细分一次，**整个模型** |
| `B` | 切角 | 把选中的角切掉：点模式切那个点，面模式切那个面的四个角 |
| `C` | 硬边 | 把选中那个面的**一圈边**标成硬边 / 取消（细分时它们不跟着变圆） |
| `X` | 删除 | 删掉选中的东西：**对象模式删整个对象**，面模式删那个面（在那儿留一个洞） |
| `R` | 旋转 | **转选中的对象**：按了之后**左右移鼠标 = 绕 Y 转、上下移 = 绕 X 转**，左键定下来，`Esc` / 右键取消 |
| `T` | 缩放 | **缩放选中的对象**（均匀）：按了之后**左右移鼠标**改大小，左键定下来，`Esc` / 右键取消 |
| `V` | 复制 | **复制当前对象**：新的一份沿画面往右错开一点，直接就是选中的 |
| `J` | 合并 | 把**选中的多个对象合成一个**（先在对象模式下 `Shift` 点多选）—— 之后整块搬、整块转、整块缩 |
| `F` | 落下 | 把选中的对象**落下去**：落到地面上，或**叠到它正下方那个对象的顶上** |
| `W` | 焊接 | 把**贴在一起的两块焊成一张连续的面**：先把选中的并成一个，再删掉中间那层夹层、并掉重合的点 |
| `U` | 并集 | 布尔并：选中两块，**合成一块**（去掉里面重叠的部分） |
| `I` | 交集 | 布尔交：**只留**两块重叠的部分 |
| `K` | 差集 | 布尔差：从**主对象**里挖掉另一个（主 = 最后点的那一个） |
| `Y` | 坐标轴 | 三条 xyz 轴**开 / 关** —— 默认不显示，按了才出来 |
| `Z` | 撤销 | 回退一步（**128 步**） |
| `S` | 保存 | 存回原处；还没存过就先问存到哪儿 |
| `O` | — | 从原处再读一遍 |

不在键盘上的按钮还有：**图元**（一排形状）、**上色**、**贴图…**、**打开…**、**导入…**、**保存**。

### 图元：先点一个形状，再在画面上左键放下

工具栏第二行是**图元**：方块 / 网格 / 圆盘 / 圆柱 / 圆锥 / 球 / 圆环 / 金字塔 / 圆台。点一个，建模器就"手里拿着"它（控制台会说
「手里是球：在画面上左键点一下就放下」）；**在画面上左键点一下**，它就在那儿落下来。落点是"屏幕上点的地方，
深度在你正看着的那个点上"。**放完手里就空了** —— 想再放一个，回面板上再点一下。不想要了按 `Esc`，或者
点一下右键。

放下来是场景里**新加的一个对象** —— 和别的东西各是各的。所以一个球挨着一个方块摆上去，它们是两样东西，
不是长在一起；雪人、桌子、房子都是这么一块一块摆出来的。新对象用和起手方块一样的灰，可以按 `1` 选面再
「上色」单独涂；`Z` 撤销。「打开…」「导入…」也一样，都是**新加一个对象**。

> 图元是**单位大小**的（和起手那个方块一样，`[-0.5, 0.5]` 那么大）。放下来之后想挪，按 `3` 切到**选对象**
> 模式，点它一下选中整块，按住左键拖 —— 见下面「选对象」。

### 选对象：整块搬一个图形

按 `3`（或面板上「选对象」）切到选对象模式，左键点一个图形，**它整个变亮**；按住左键拖，整块跟着走
（Shift 吸附到 0.05 的格子）。**场景是一串对象** —— 每个图元、每次导入、每张图片都是**一个对象**，所以
点中的就是那一个，拖的是它的位置。面/点模式（`1` / `2`）动的是**当前对象内部**的网格，不动别的对象。

> 默认拖的范围是**正对相机的那一个平面** —— 屏幕上怎么拖，它就在那个平面上怎么走；**沿着视线方向**
> （深进去、拉出来）那一段鼠标表达不了。想精确挪某个方向，**拖着的时候按 `X` / `Y` / `Z` 锁到那根
> 世界轴**，它就只沿那根轴走（再按同一根解开，回到自由）。拖面、拖点用的是同一套。
>
> 对象**不会掉到地面以下** —— 最低点顶多贴到地面上（地面在 `y = -0.5`）。因为地面是一块**不透明**的
> 格网，掉下去就整个看不见了。

### 多选和合并：把一个东西拼出来

**对象模式下 `Shift` + 左键点**，就把对象**加进选中**（再点一次移出）。选中的**每一个都亮着**，
**拖一个就是整批一起搬**，`X` 也是整批删。

选中两个以上后按 **`J`**（面板上「合并」）→ **合成一个对象**：桌面 + 四条腿拼成一张桌子，之后整块搬、
整块转、整块缩。合并是取编号最小的那个当"底"，把别的对象**按各自的摆放搬到世界、再换算进底对象里**
（点、面、颜色、贴图、硬边都并进去），所以拼出来的东西和你看到的**一模一样**；导出也是**一份 `.model`**。
`Z` 撤销。

**`F` = 落下**：把选中的对象往下放 —— 落到**地面**上，或者**叠到它正下方那个对象的顶上**。搭场景最常用
的一下（把箱子放到箱子上面、把桌子腿落到地上）。它看的是 XZ 投影有没有交叠。

**`W` = 焊接**：把**正好贴在一起的两块**合成**一张连续的面**。它先把选中的并成一个（和 `J` 一样），
再把两块之间那层**内部夹层删掉**、落在一起的点并成一个 —— 于是"两个方块面对面贴着"焊完就是**一个干净的
盒子**，中间没有夹层。它**只管正好贴着的**（面完全重合，用 `F` 落下 / 吸附对齐摆出来的就是这种）；
斜着插进去、在墙上挖个洞，那是**布尔运算**，见下面。

**布尔运算（`U` 并 / `I` 交 / `K` 差）**：选两个对象（`A` = 最后点的主对象、`B` = 另一个），把两块
几何在**世界空间**里做 CSG —— 并 = 合成一块（去掉重叠），交 = 只留重叠，差 = 从 A 挖掉 B。结果留在
`A` 身上（名字、摆放不变），`B` 删掉。切出来的面是**三角形**，共面/退化的极端情况可能有瑕疵 —— 对图元
拼出来的形状够用。

> `Shift` 点在**空处**不改变选中，而且**拖着平移画面**；点在**对象上**才是加选 —— 这两件事看点在哪儿
> 分开，不会打架。
>
> 对象能**平移**（左键拖）、**旋转**（按 `R` 移鼠标：左右绕 Y、上下绕 X）、**缩放**（选中它直接
> **滚滚轮**，或者按 `T` 左右移鼠标；**均匀**缩放）和**复制**（按 `V`）。旋转只有 Y、X 两根轴（`.scene`
> 的摆放指令 `T · Ry · S` 表达不了更多），所以**导出时把旋转烘进网格**；而平移和缩放是**原生**写进
> 场景的。没有绕 Z 的滚转、也没有不均匀缩放。

### 大纲：左边那一列

画面左边是一列**对象**（和 Blender 的 Outliner 一个位置）：场景里有几个、各叫什么，一眼看全。**点一行
就选中它** —— 视口里那个对象亮起来（会顺手切到对象模式）。列表和视口是**双向**的：你在视口里点中一个
对象，列表的高亮也跟着走。对象增删（放图元、导入、插入图片）列表会自己更新。

### 插入图片：往场景里放一张画

点工具栏的「插入图片」，挑一张 **BMP** —— 它会在**画面中央**放一块贴着这张图的平面（长宽比按图来，
不拉伸）。那块平面**正对着你按下时相机看的方向**（对象只会平移，所以朝向是放下那一刻烘进点里的）。
和别的图元一样是一个对象：按 `3` 能整块选它、整块拖。

### 导出场景：交给游戏

点「导出场景」，挑一个 `.scene` 的位置。它会写出：

```
out.scene       场景本身（相机、灯光、背景，和每样东西摆在哪）
out_0.model     第 0 个对象
out_1.model     第 1 个对象 …
tex.bmp         用到的那张图（拷过来）
```

**用到的图会拷到场景旁边**、路径改成文件名 —— 所以这一个文件夹可以**整包搬走**。游戏那边是现成的
`LoadScene`：`zlong_render_scene --scene out.scene out.bmp` 就能把它渲出来。（地面网格、三条轴、选中的
高亮都是**编辑器外壳**，不在导出的场景里。）

## 四、从零捏一个东西

进去的时候手上有**一个单位立方体**（`[-0.5, 0.5]³`，一种灰材质）。下面是一个完整的例子：

**① 选一个面，挤出一层**

```
按 1          切到选面
左键点立方体  选中一个面 —— 控制台会说「面 1 / 共 6 个，距离 4.19」
按 E          挤出一层，新面自动选中
Shift + 拖    把它吸到格子上，或者再按 E 长第二层
```

**② 让棱是棱：标硬边，再细分**

细分会把棱角磨圆（"盒子变球"）。想保住某条棱：

```
按 1 选中那个面
按 C          这个面的四条边成硬边 —— 控制台会说「这个面的 4 条边硬了」
按 D          细分一次
```

硬边上的点在细分时走的是另一条规则（边点取中点、两条硬边的交点走折线规则），所以**那一圈棱
还是棱**。再按一次 `C` 就取消。

> 为什么硬边绑在"一个面的整圈"上：这台工具只选面或者点，**没有"选边"这回事**，而硬边是一张
> **边的表**。想要一条硬边连过去，就沿着它把两边的面各按一次 `C`。

**③ 切角**

```
按 1 选中一个角所在的面
按 B          那个面的四个角各被切掉一块（切进去 28% 的边长）
```

或者按 `2` 切到选点，点中一个顶点再按 `B` —— 只切那一个角。

**④ 挖个洞**

```
按 1 选中一个面
按 X          面没了，那儿是一个洞；没人指着的点会跟着丢掉
```

**⑤ 上色、贴图**

```
选中一个对象（按 3 点它，或点左边那一列）→ 面板上「上色」→ 挑一个颜色　（整块换色）
选中一个面（按 1 点它）→ 面板上「上色」→ 挑一个颜色　（只换那个面）
选中一个面 → 面板上「贴图…」→ 挑一张 BMP
```

**⑥ 存下来**

```
面板上「保存」→ 挑一个地方（比如 我的游戏/方块.model）
之后按 S 就是存回同一个地方
```

然后在游戏里：

```cpp
zlong::engine::MeshDescription model;
std::string why;
zlong::engine::LoadModel("方块.model", model, why);
```

`.model` 里那个**贴图的路径是相对它自己**的，所以模型和贴图可以整包一起挪走。

## 五、那四个改拓扑的操作

捏一个小东西靠这四个。**它们都会压一步撤销**，所以按错了 `Z` 就回来。

| 操作 | 做什么 | 面会变多还是变少 |
|---|---|---|
| **挤出** `E` | 一个面沿它自己的法线挪一段，四周补上侧壁。**那个面会被换掉**（留着就是一块内部墙） | 多 |
| **细分** `D` | Catmull-Clark 一次：每个面一个中心点、每条边一个点、每个老顶点按邻域挪一下 | 多 |
| **切角** `B` | 点到的每个顶点各用一小片平面切掉，再补一片封口面 | 多 |
| **删面** `X` | 删掉一个面，在那儿留一个洞 | **少** |

### 两件要知道的事

**挤出**：给负的距离就是往里挤，侧壁的绕序会跟着翻，法线仍然朝外。新面**在最后一个**，所以挤完
它自动是选中的 —— 连按几次就是稳稳的几层。

**切角**：一个角一削，面就可能不是三四个角了（三角形三个角都削是六边形），而引擎的面只放得下
四个角，所以**五个角以上的面从它的中心扇成三角形** —— 都在原来那张面上，形状一点没变。
一个顶点如果落在**边界**上（有边只挨着一个面），它切出来的不是封口是一道豁口，所以那种**拒绝
执行**，控制台会说清是哪个点。

## 六、硬边

**硬边 = "细分的时候这条边不跟着变圆"。**

它是**一张边的表**，不是挂在面或者角上的东西。细分的时候：

- 硬边的**边点**取**中点**（不是"两端点 + 两个面心"的平均）→ 那条边细分完还是直的
- 一个点上连着**两条**硬边 → 沿这两条走折线规则 `(6P + Q₁ + Q₂)/8`，硬边连成的线细分完还是硬的
- **三条以上** → 那是个尖角，钉住
- 一条或零条 → 走普通规则（孤零零一条硬边撑不住一个角）

切角和删面的时候，硬边也跟着收 —— 不会一声不响地丢掉。

## 七、材质和贴图

### 逐面材质

「上色」给**选中的东西**换一种颜色：**对象模式下整块对象**（它的每一个面都换），**面模式下那一个面**。
**同一个颜色会复用同一个材质槽** —— 涂十次同一个红不会长出十种材质。

引擎那边一个可画节点配一种材质，所以"一个东西上有两种颜色"在那一侧就是"两个节点"。建模器在画的
时候**按材质把模型拆成几块** —— 管线和着色器一个字不用改。

### 贴图

「贴图…」挂的是**那种材质**，不是那一个面。材质是好几个面共用的，所以给一个面上贴图**常常会同时
给另外几个面也贴上** —— 控制台会说清是哪种材质。

读的是 **BMP**（24 位或 32 位、不压缩）。图的路径**尽量存成相对的**，那样模型和贴图能一起搬走。

## 八、`.model` 文件格式

模型存成**文本**，于是模型是数据，不是一次会话。格式在
`引擎/include/zlong/engine/model_file.h`，长这样：

```
mesh 4
material 0.62 0.64 0.68 1 0.35              没有贴图的
material 0.90 0.20 0.20 1 0.30 木纹.bmp     有贴图的，路径在最后
v -0.500000 -0.500000 -0.500000
v  0.500000 -0.500000 -0.500000
f flat   4  0  0 3 2 1   0 0   1 0   1 1   0 1
crease 0 3                                  一条硬边
```

| 行 | 是什么 |
|---|---|
| `mesh 4` | 版本。**3 也认** —— 老文件只是没有 `crease` |
| `material R G B A [高光] [贴图路径]` | 一种材质。**贴图在最后**（路径里可以有空格，所以它一直到行尾） |
| `v x y z` | 一个点 |
| `f <flat\|smooth> <几个角> <材质号> <角…> <uv…>` | 一个面。**几个角写在材质号前面**，后面那串从哪儿切就明确了 |
| `crease <低号> <高号>` | 一条硬边。没有硬边的文件一行也没有 |

**uv 写在面上，不写在点上。** 一个点是空间里的一个位置、几个面共用它；而 uv 说的是"这个面的这个
角贴到贴图的哪儿"，同一个位置在不同面上可以贴在贴图的不同地方。这正是那份描述**焊接**起来的
意义。

**点要写在面前面**：角的下标是照着**已经读到的**点算的，于是读错的时候能说出一句
"第 4 行那个角是 2，前面只有 2 个点"。

**一个 float 写九位有效数字**（float 的保证往返数）—— 少一位就会"每存一次模型悄悄变一点"。

## 九、导入别人的网格文件

面板上的「导入…」读的是 **OBJ**。出来的就是同一个 `MeshDescription` —— 所以"捏的"和"导的"在这一
点上合成了一件事。

**导入是有损的**，它会**把账报在控制台里**：

```
导入了 棋子.obj
  点 1204 → 986（218 个没被面用到，丢了）
  面 640 → 812（44 个五个角以上的扇成了三角形），平 640 滑 0
  跳过 88 行用不上的（物体名、材质那些）
```

| 有损的地方 | 为什么 |
|---|---|
| 五个角以上的面**扇成三角形** | 引擎的面只放得下三或四个角 |
| 没被任何面用到的点**丢掉** | 一份描述里不该留着一个谁也不指的点 |
| 导进来之后**没有"存到哪儿"** | 那是别人的文件，按 `S` 不该往它上面写。想留下就「保存」另存一个 |

**`usemtl` 现在还是跳过的** —— 导进来的东西一律白材质，要上色得自己涂。

## 十、它画在哪儿

**对着建模的那块画布，就是游戏将来显示用的那一个渲染器**（Vulkan），不是它的预览。所以你在里面
看到的光、影、材质，就是游戏里会有的。

画面是**按面板的形状**出的：面板多宽多高，建模器就出多宽多高的图，一条黑边都不留。

> 建模器的默认值是从量出来的数里挑的：**800×500 且不要阴影图**（53.7 帧）。阴影图是一笔和视口
> 无关的账 —— 1024² 要把帧率从 54 打到 9。建模的时候影子帮你判断东西落没落在地上，所以它是
> `--shadow 1024` 一句话的事，但不是默认。
>
> 面板比 800×500 宽的时候，编辑器会**按面板的形状**给它尺寸，但**像素总数保持 800×500 那份量**
> —— 图铺满，帧率不动。

## 十一、命令行参数

一般用不着（编辑器会自己给）。要手动起：

| 参数 | 默认 | 是什么 |
|---|---|---|
| `--width N` `--height N` | 800 × 500 | 出图多大 |
| `--shadow N` | 0（关） | 阴影图多大。`--shadow 1024` 会把帧率从 54 打到 9 |

## 十二、现在还不能做什么

| 不能 | 说明 |
|---|---|
| **选边** | 只选面或者点。硬边是"一个面的整圈"一次标的 |
| **倒角边** | 做的是**切角**（把顶点切掉）。真正的"倒角边"在焊接的网格上必然要把端点**劈成几个**，那是另一件事 |
| **多选** | 一次选一个面 / 一个点 / **一个对象**，没有框选、没有加选、没有"一次拖几个" |
| **没有不均匀缩放、不能绕 Z 滚转** | 能平移、能绕 X/Y 转、能均匀缩放；这两样还没做 |
| **图元的大小** | 放下来的一律**单位大小**，放下的时候不能改大小（引擎那几个形状的参数是写死的默认值） |
| **展开 uv** | 贴图落在 uv 本来就在的地方，没有拖 uv 的地方 |
| **内插 / 环切** | — |
| **骨架 / 蒙皮 / 动画** | 一个字都没写 |
| **`usemtl`** | 导入不带材质 |
