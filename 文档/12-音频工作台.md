# 音频工作台

`宿主/audio`（编辑器里「音频」那一页起的那个工具）—— **把声音摆进世界里，边看边听边改**。

它是编辑器上的第二个工具，和建模器同一个形状：**没有自己的窗口**，画面走面板，鼠标键盘走管子；
它实现 `Platform` 交给 `System`，不组装机器也不跑循环。唯一的区别是它**出声**。开法和别的宿主
一样：编辑器里按「音频」，或者自己设 `ZL_EDITOR_HOST=1` 发

```bat
build-zig\宿主\zlong_audiotool.exe --width 800 --height 500
```

（CMake 目标叫 **`zlong_audiotool`**，不是 `zlong_audio` —— 后面那个名字已经是 `内核/audio`
那层音频库了。包里是 `音频器/音频器.exe`，见 [07-打包与发布](07-打包与发布.md)。）

---

## 从零走一遍

**做一首背景音乐**

1. 菜单「从模板新建 → **曲子**」，存成 `主题.song`。**模板本身就是一份能听的曲子** —— 先按下面第 2
   步放进来听一遍，知道它长什么样再改。
2. 「音频」页按「**导入音乐…**」选它。它**循环**响着（背景音乐就该一遍一遍地放），而且是**全局**
   的 —— 站哪儿听都一样。左下的**音符格子**同时出来了。
3. 在格子上编：**点空格子加一个音**、**拖着它挪**、**拉右缘改长短**、**右键删**；上面两个框改速度和
   一遍多少拍。改一下立刻重渲染，边看边听。
4. 「**乐器…**」编音色：波形 + 包络 + 增益 + 低通，改一下就听得到；「试听」可以循环响一串**带节奏**
   的音（`60:1 64 64 -:0.5 67:0.5` 这种写法）。
5. 「**保存曲子**」写回 `.song` —— **不按它，磁盘上那份还是旧的**（和建模器里"改了模型要按保存"同
   一条规矩）。
6. 「**保存**」把这一份写成 `.scene` —— 里面就是一行 `sound song 主题.song`，加一个全局的发射器。

**做音效**

1. 「**音效**」拿在手里（想用现成素材就「导入 WAV…」），在画面上左键放一个。
2. 「**音效…**」调参数：波形、起始/结束频率（下滑的 zap、上升的 swoosh）、ADSR、低通。
3. 拖着它在世界里挪 —— **挪到哪边就从哪边听得到，走远了就轻下去**（世界里的声音就是这么回事，和
   背景音乐不一样）。
4. 和曲子一起「保存」进同一个 `.scene`。

**交给游戏**：一份 `.scene` 加它引用的 `.song` / `.wav`，就是一个能整包搬走的目录。游戏那边读这个
`.scene`，**出声的是引擎自己那一层**（不需要 FMOD / Wwise 那种中间件）—— 见
[09-游戏开发范式](09-游戏开发范式.md)。

> 也可以**完全手写**：`.song` 和 `.scene` 都是文本，这个项目的东西本来就是"写"的。格式见下面
> 「背景音乐（`.song`）」和 [03-引擎](03-引擎.md) 的场景文本一节。

## 它是怎么"听"的

三件事决定了这个工具的手感，它们都不是这里定的，是**引擎本来就有的那几条法**，这里如实照着：

1. **听者就是相机。** `SoundRenderer` 拿 `scene.camera` 当耳朵（`引擎/src/sound.cpp`），视口画
   的也正是这台相机。所以**转视角 = 转头**：左右一拖，所有声源的声像跟着走。
2. **一个声源一个球，球越大越响。** 球的大小直接画的就是那个声源的增益（`0.22 + 0.45·gain`），
   选中的是暖色（`1.0, 0.62, 0.18`），静音的是灰色。一眼看得出哪一段在主导。
3. **声音是每帧现混进声卡的。** 见下面「实时混音」。

一进来就有两个声源可听：一段 220 Hz 的低音铺在中间（循环），一段 880 Hz 的钟挂在右前方。

## 鼠标和按键

| 动作 | 怎么做 |
|---|---|
| 选一个声源 | **左键点它那个球**（挑的是**屏幕上隔多远**，不是世界距离 —— 离得远的东西看起来就小） |
| 挪一个声源 | 点在球上**按住左键拖**；拖的平面是**过它、正对相机**的那一个 |
| 转视角（= 转头） | **右键拖动**；或者左键拖空处 |
| 平移 | **中键拖动** |
| 远近 | **滚轮** |
| 播放 / 暂停 | **空格** |
| 循环 | `L` |
| 静音 | `M` |
| **全局 / 定位**（跟不跟位置走） | `G` |
| 删除选中的声源 | `X` |
| 换一个声源 | `↑` / `↓` |
| 撤销 | `Z` |
| 手里拿上「音调」/「噪声」/「音效」 | `1` / `2` / `3` —— 然后左键放到画面上；`Esc` 取消 |

拖动的两个规矩和建模器一样：**从按下那一刻的位置算起**，不在上一次结果上累加（不漂移）；按下那一
帧的整份状态留一份，撤销放回去的就是它。

## 面板上那几排按钮

按钮**不自己实现任何东西**，只替用户敲键或者发一个值。这是从建模器那一页原样搬过来的规矩，
协议在 [05-编码器](05-编码器.md) 的「鼠标」一节。

**「键」那一排**发 `K <虚拟键码> 1` —— 和上面那张键盘表一一对应（播放/暂停 = 空格 32、循环 = `L`、
静音 = `M`、删除 = `X`、上一个/下一个 = 38/40、撤销 = `Z`）。

**「声源」那一排**发 `P <号>`（1 音调、2 噪声、3 **音效**）—— **是"值"那一类**，敲键带不走它：点一下**拿在手
里**，下一次左键把它放在画面上，放完就回到选择（一次性）。和建模页那排图元一个走法。

**「参数」那一排**发 `V <名字> <数…>`：

| 按钮 | 发的 | 意思 |
|---|---|---|
| 响一点 / 轻一点 | `V gain 0.1` / `V gain -0.1` | 选中声源的音量**加 / 减**这个数（夹在 0..4） |
| 整场响 / 整场轻 | `V master 0.1` / `V master -0.1` | 整场音量加 / 减（夹在 0..4） |
| 参考距离 ± | `V reference ±0.5` | 满音量的范围（夹在 0..max） |
| 最远 ± | `V max ±2` | 再远就听不见的距离（夹在 reference..200） |
| 频率… / 长度… | `V freq <数>` / `V length <数>` | 弹框问一个**绝对值**，设给选中的声源 |
| 音效… | `V wave` `V freq` `V length` `V envelope` `V cutoff` | 一个对话框，把选中的**合成音效**调一遍（见下） |
| 全局 | `V global` | 让选中的声源**不跟位置走**（满音量、居中）；再按一下变回去（键 `G`） |

**带符号的是"加这个数"，不是"设成这个数"。** 面板不知道当前值是多少（程序没往回报），所以能加减
的就说成加减；要设绝对值（频率、长度）就弹一个框问。每次改都会把新值打在控制台里：
`低音 音量 0.70`、`钟 频率 880 Hz`。

**「文件」那一排**（路径只能从管子里来，理由见 [05-编码器](05-编码器.md)）：

| 按钮 | 发的 | 干什么 |
|---|---|---|
| 打开… | `L <路径>` | 读一个 `.scene`，把它**声音那一半**变成声源 |
| 导入 WAV… | `I <路径>` | 读一个 `.wav` 放进世界（循环打开） |
| 导入音乐… | `U <路径>` | 读一份 `.song`（一首曲子）放进世界（**循环、全局**） |
| 保存 | `S <路径>` | 把这一份写成一个 `.scene` |
| 导出 WAV | `E <路径>` | 把**当前这一份**整体混成一个文件 |

## 声音从哪来

- **音效（合成）**：一段**描述**渲染出来的 —— 波形 + 音高走向 + 幅度包络 + 一个低通。见下一节。
  做音效主要用它。
- **音调 / 噪声**：程序里合成出来的（`MakeTone` / `MakeNoise`，后者是定种子的 LCG —— 同一个种子，
  每次都是同一段噪声）。摆一个就多一段。它们是音效那条路的退化情形（平包络、单一音高），留着是因为
  `demo.scene` 和混音器的逐字节校验还靠它们。
- **导入 WAV**：`引擎/include/zlong/engine/wav_file.h` 的 `LoadWav`。全项目在这之前**只有 WAV
  写、没有 WAV 读** —— 这个头是另一半。
- **背景音乐（`.song`）**：一首曲子是一个文件（音符过时间），「导入音乐…」把它放进来。见下下节。

**WAV 读取器认得很窄，而且是故意的**：**16 位 PCM**（`wFormatTag == 1`）、**单声道或双声道**、
**任意采样率**（混音器本来就做线性重采样，44.1k 的素材直接放得对）。别的——压缩格式、IEEE float
（格式 3）、`WAVE_FORMAT_EXTENSIBLE`、24/32 位、多于两个声道——**一律拒绝并说清是哪一种**，因为
一段声音读成噪声比读不出来坏得多（和 `image_file.h` 对 BMP 一个态度）。单声道铺到**两边**，不是
丢一半。文件是截断的（某个块写的大小超过了文件剩下的字节）也拒绝。

## 音效（合成）

按「音效」（`P 3`，键 `3`）拿在手里，在画面上左键放一个 —— 默认是一声**下滑的激光**。选中它，
按「音效…」开一个对话框，把这几个数调一遍（改完**立刻重渲染**，边听边调）：

| 参数 | 是什么 |
|---|---|
| 波形 | 正弦 / 方波 / 锯齿 / 三角 / 噪声 |
| 起始频率 `f0`、结束频率 `f1` | 音高的走向。相等 = 不变；不等 = 一次滑音（下滑的 zap、上升的 swoosh）。**线性走 Hz**，所以听感上前段掉得快、后段掉得慢（等音程的指数滑音是后来的旋钮） |
| 长度 | 秒 |
| 起音 / 衰减 / 持续电平 / 释音 | **ADSR**：起音升到 1、衰减降到"持续电平"、保持、释音降到 0。四段**按长度铺满**（配得比长度还长就按比例缩），所以"一段音效多长"只由"长度"一个数说了算 |
| 低通 | 单极点低通的截止，Hz；**0 = 关**。这是"音色"那一档：噪声的闷与脆、声音的暗与亮 |

对话框一趟发五条 `V`（`V wave 0..4` / `V freq f0 f1` / `V length 秒` / `V envelope a d s r` /
`V cutoff hz`），程序收到就照那份配方重渲染那一段。**初值不是面板猜的**：程序把活动音效的配方
**回推**过来（声源表里多一行 `\x01zl synth …`），所以打开一个**存过的**场景再点「音效…」，显示的是
文件里那份。

> 波形是**朴素**的（方/锯/三角直接由相位算），所以有混叠 —— 短音效里听不出多少；band-limit 是后来的
> 旋钮。包络是**线性**的（和这一层"可预料"那条口味一致：线性衰减、线性重采样）。**这一版没有滤波器
> 栈、没有混响/延迟**，只有一个单极点低通当代"颜色"。

## 背景音乐（`.song`）

**一首曲子是"音符过时间"**：速度（BPM）、一遍多少拍、几件乐器、一串音符。它和 `sound synth` /
`sound wav` 是同一类东西——一个**产生 `Clip` 的东西**——所以 BGM 就是把它当一段声音交给一个发射器
放。引擎里 `RenderSong(spec) -> Clip`（`song.h`），文件是 `.song`（`song_file.h`）。

**一件乐器就是一段 `SynthSpec` 去掉音高和长度**（那两样由音符给），所以 DSP 仍然只有 `RenderSynth`
那一份，没有第二套采样器。`RenderSong` 逐音符渲染、**相加**；越过一遍末尾的那截**绕回开头** ——
一段会循环的音乐不能在接缝处"啪"一声。

```
song 1                                   # 版本号
tempo 120
loop 4                                   # 一遍四拍
instrument 0 wave triangle attack 0.01 decay 0.12 sustain 0.6 release 0.2 gain 0.5 cutoff 0
instrument 1 wave noise    attack 0.001 decay 0.05 sustain 0   release 0.02 gain 0.6 cutoff 5000 seed 7
note 0 1 60 0.9 0       # 第 0 拍起、1 拍长、MIDI 60（中央 C）、力度 0.9、乐器 0
note 1 1 64 0.85 0
```

**音高是 MIDI 号**（`60` = 中央 C，`69` = A4 = 440 Hz，十二平均律）；**音符那一行是位置式的**五个数，
**乐器那一行用关键字**（和 `sound synth` 一字不差的一套键 —— 同一份东西不该有两种写法）。乐器要写在
音符前面。

**一行一条指令**，空白分隔，`#` 起注释，第一行是版本：

| 行 | 意思 |
|---|---|
| `song 1` | 版本号，**必须在第一行** |
| `tempo <BPM>` | 速度，正数 |
| `loop <拍数>` | 一遍多少拍，正数 —— **渲染出来的长度就是它** |
| `instrument <编号> [wave NAME] [attack F] [decay F] [sustain F] [release F] [gain F] [cutoff F] [seed N]` | 一件乐器。编号要**从 0 连着**；**要写在用到它的音符前面**；省掉的关键字用默认值 |
| `note <起点拍> <长度拍> <音高> <力度> <乐器编号>` | 一个音符。起点和长度是拍，音高是 0..127 的 MIDI 号，力度 0..1 |

认不出来的指令、越界的音高、非正的长度或速度、指到不存在的乐器 —— 一律**拒绝并带行号**。

**音符可以重叠**（`RenderSong` 把它们**相加**）：低音垫在下面、主旋律走上面，就是两条 `note` 在时间上
叠着 —— 和弦和多声部都是这么写的。

**音符格子就是编它的地方**（见下一节）。也可以**手写**：**菜单「从模板新建 → 曲子」** 起一份
`.song`，在代码那一页当文本编（和 `.scene` / `.model` 一样，这个项目的东西本来就能**写**）。
两条路都通向同一个 `.song`。

**「导入音乐…」放进来的一首曲子：默认循环、默认全局。** 循环是因为背景音乐就该一遍一遍地放；**全局
是因为会跟着位置跑的背景音乐不是背景音乐** —— 它不按距离衰减、不按方向声像，就是满音量、正中
（引擎那一侧是 `Emitter::spatial == false`，场景文本上是 `emitter … global`）。按「全局」（键 `G`）
可以把它变回一个世界里的声源 —— 那样它就变成一个"在哪儿响"的东西了。**全局的球是青的**，一眼看得出
哪个不跟位置走。

## 音符格子（时间线）

在左边选中一首曲子，这一页下面就会多出一块**音符格子**：横轴是拍，纵轴是音高，一个音符一个方块。
上面一排是 `速度(BPM)`、`一遍(拍)`、「保存曲子」、「乐器…」。

| 动作 | 怎么做 |
|---|---|
| 加一个音符 | **点空格子** —— 在那条拍、那一行上放一个 1 拍长的 |
| 挪 | **在音符上按住左键拖**：横向跟手（吸附到 1/4 拍），**纵向看拖到哪一行** —— 那一行就是音高 |
| 改长短 | 拖一个音符的**右缘**（右边 6 像素以内） |
| 删 | **右键点它**；或者选中它按 `Delete` / `Backspace` |
| 改速度 / 一遍 | 上面那两个框，回车或点别处生效 |
| 存下来 | 「保存曲子」（`B <路径>`）—— 不按它，磁盘上那份 `.song` 还是旧的 |
| 编乐器 | 「乐器…」—— 波形 / 包络 / 增益 / 低通，见下 |

**改一下就立刻重渲染那一段**，所以边看边听；每一步都压一次撤销栈（`Z` 收回）。

**模型不在这一头。** 曲子的真相是宿主里那份 `SongSpec`（C++）；格子**只是把宿主推过来的音符画
出来、把鼠标动作发回去**（`编码器/timeline.py`）。这是这一步唯一一个真正的选择，另外两条路都更贵：
让宿主把格子画成像素（引擎只会画 3D 网格配贴图，2D 要么每帧更新一张贴图 —— 那会把声音一直重启 ——
要么在宿主里手写光栅化），或者在 Python 里再存一份模型（两份一定会走散）。

推过来的是 `\x01zl song <速度> <一遍> <乐器数>` 加一串 `\x01zl note <起点> <长度> <音高> <力度>
<乐器>`；发回去的是 `V note_add / note_move / note_len / note_del / tempo / songloop` —— **编辑全是
"值"，走的是现成的 `V` 那条线**。**`songloop` 不叫 `loop`**：`loop` 已经是"这个声源循环不循环"那个
开关了，一个名字只能有一个意思。

**播放头**：格子出来的时候面板发一次 `R 1`（收起来发 `R 0`），宿主就每 50ms 回一行 `play <拍>`。
那个位置是宿主**自己累加墙钟**算的 —— `OnMix` 给的那个秒数每次混音都从 0 起
（`内核/system/src/system.cpp` 的 `done / rate`），拿它当播放位置会一直跳回开头。暂停时不报，
播放头停在原地。

**这一块还没有的**：缩放、横向滚动（整遍铺满格子，很长的曲子格子会很细）、力度编辑、多选 /
复制粘贴 / 框选。吸附固定 1/4 拍，关不掉 —— 点击那条线（`viewport.py` 的 `C`）不带修饰键，
做不了"按住 Shift 不吸附"。

### 乐器编辑器

同一排的「**乐器…**」开一个对话框，编这首曲子的那几件乐器（`Instrument`：波形 + ADSR + 增益 +
低通）。左边是列表，右边是参数；**改一下就发**，没有确定/取消，只有「关闭」—— 设计音色的手感就是
"调一个数听一下"。

它和「音效…」那个对话框是**同一族**的东西，区别只有一个：**乐器没有音高和长度** —— 那两样由音符给
（`song.h` 里 `Instrument` 砍掉 `f0/f1/seconds` 就是为这个）。所以这里只有六个框（起音/衰减/持续/
释音/增益/低通）加一个波形。

| 按钮 | 发的 | 意思 |
|---|---|---|
| （改任意一个参数） | `V instrument <序号> <波形> <起音> <衰减> <持续> <释音> <增益> <低通> <种子>` | **一口气设整件乐器** —— 改一个数就整件发一遍，原子 |
| 新增乐器 | `V instrument_add` | 追加一件默认的（正弦、中庸包络） |
| 删除乐器 | `V instrument_del <序号>` | 删一件；有两件事它**会拒绝并说清为什么**：还有音符在用这件乐器、或者只剩这一件 |
| 试听 / 停止试听 | `V instrument_play <序号> <音高> <秒> …` / `V instrument_stop` | 拿这件乐器**循环**响这一串（一对一对的：音高 + 多长；音高 `-1` 是休止）。一对都不给就是中央 C |

**试听是这一步里唯一有点设计的活**，也值得说一句它怎么实现的：宿主把试听渲染成的一段挂在场景里，
`Rebuild` 时**追加在最后**一份 sound + 最后一个 emitter 上（非空间、循环）。追加在最后，现有声源的
序号一个都不动 —— 靠 `SoundRenderer::Prepare` 那条"同一段接着放"的规矩，**整首曲子不会被打断**，
试听叠在上面响。

**为什么是循环而不是放一次**：设计音色要的是"它一直响着，我边调边听"；而且循环顺手绕开一个坑 ——
同一个声音再按一次试听，靠 `Load` 是重启不了的（指纹没变，游标留着），循环不需要重启。改一个参数，
样本立刻换成新的，游标不动。

**试听那一串音可以带节奏**：那排下面是「试听音序」和「默认」（秒）。音序里一步写成三种样子之一 ——

| 写法 | 意思 |
|---|---|
| `60` | 一个音，用「默认」那个长度 |
| `60:0.5` | 这个音自己的长度（0.05–8 秒） |
| `-:0.5` | **休止**（静音这么久）—— 节奏就是"什么时候响、什么时候不响" |

比如 `60:1 64 64 -:0.5 67:0.5` 是"一个长音、两个短音、停一下、再一个短音"。旁边那条写着音名和**总共
多长**（休止画成 `·`）。**一个音也是一串**，只是长度 1 —— 想只听一个就只写一个。

- **只改音高（步数和每一步的长度都不动）声音不停** —— 换音高和改参数是同一件事：换一份样本，而帧数
  没变，指纹就没变，播放游标留着。
- **改步数（加/少一个音或休止）、或者改某一步的长度，那一个就从头来** —— 帧数变了，指纹跟着变。
- 在列表里换一件乐器时，试听也跟着**挪过去** —— 不然你会一边编着 B、一边听着 A 响。

试听**不进 `SaveScene`**（那按 `sources_` 写），**也不进「导出 WAV」**（试听永远是最后一份 sound +
最后一个 emitter，导出前去掉一对就行）—— 一份导出的曲子不该把"我正在试的那件乐器"也录进去。
**关掉对话框一定停下试听**（`accept` / `reject` / `closeEvent` 三条路都停了）。

**这条线上还没有的**：一件乐器还是一层（没有叠加、没有滤波器包络、没有 LFO）；没有 per-note 的音色
（力度只影响音量）；试听那一串是**一件乐器、首尾相接**的 —— 没有和弦（同时响几个音），也没有每个音
自己的力度；删乐器**不重排音符**（所以"还有音符在用"
就直接拒绝，而不是偷偷把它们改到别的乐器上）。

## 存 / 读：`.scene` 的声音那一半

**不新造音频文件格式。** 一份 `Scene` 本来就同时描述看得见和听得见的东西，`.scene` 文本里 `sound`
/ `emitter` / `master` 那几行早就在解析器里了。这一轮给这套格式补了两样：

- **读**：`sound wav <路径>` —— 一段真的声音，路径一直到行尾（可以有空格），**相对场景文件自己的
  目录**，和 `texture file` / `model` 一条规矩。它和既有的 `sound tone <频率> <秒>`、
  `sound noise <秒> <种子>`、`sound synth wave … f0 … envelope …`、`sound song 主题.song` 并列。
- **写**：`SaveScene` 现在会写声音/发射器/master 了（`SceneDescription` 多了 `sounds` / `emitters`
  / `master_gain`）。**写的是"源形态"**（`sound tone 440 0.5` 那一行），不是 PCM —— 一段合成音没法
  从它最终的样本反推回那一行，所以记住的是"它是怎么来的"。WAV 和 `.song` 那种**会把文件拷到场景目录
  旁边**，和贴图一样，一份场景要能整包搬走。

「保存」写的是**当前这一份**：每段声音一行 `sound`，每个声源一行 `emitter <声音号> -1 <x> <y> <z>
gain … reference … max … [loop] [global]`（摆在**世界坐标**里，因为工具里的声音就是直接摆在世界里
的），最后一行 `master`。**几何是空的** —— 这个工具不管画的东西。

「打开」读回来的也只有声音：**场景里的网格、材质、节点一概不管**。为了让"读回来还能再存出去"这句
话成立（一段合成音要能重新写成 `sound tone …`，一段合成音效要能重新写成 `sound synth …`，一首曲子
要能重新写成 `sound song …`），读的时候会**自己再看一遍那个文本里 `sound` 那几行**，把每一段的"源"
记下来（`ScanSounds`），再和 `Scene::sounds` 按序号对上。对上的是 WAV/曲子却没有
文件路径的那种，保存时会**明确拒绝整份**（`「X」是 WAV，可是不知道它原来在哪个文件，整份不写`）
—— 和 `SaveModel` 拒绝没有路径的材质一个态度。

上次用的那个 `.scene` 记在 `QSettings` 的 `audio/scene` 里，进这一页会读回来。

## 导出 WAV

「导出 WAV」把当前这一份整体混成一个文件，用的是**另起一份 `SoundRenderer`** —— 不碰机器里那一路
正在响的，所以导出不影响你耳朵听到的东西。长度取"够把最长的那一段放完"（循环的那些封顶 4 秒）。

## 实时混音（这是这一版最要紧的一处）

`System::Run` 只管渲染，`System::Mix(seconds)` 才混音。这个工具的做法是：**在 `OnFrame` 里，按真实
流逝的墙钟时间混那一小块交给声卡**（`宿主/audio/main.cpp` 的 `OnFrame`）。

三个点值得记住：

- **不能拿 `OnFrame` 给的 `last_frame_seconds` 当混音长度。** 那个数在 `System::Frame` 里是
  **渲染耗时**（`Clock::now() - started` 包着 `renderer_->Render`），不是帧间隔 —— 拿它混会一直少混。
  所以这里自己拿 `steady_clock` 量一个增量。
- **声卡就是时钟。** `Submit` 在队列满的时候会挡住（见 `宿主/audio_device/wasapi_sink.h`），于是帧
  的节奏跟着"已经播出去的时间"走，而不是跟着渲染多快走。一次卡顿之后最多补 `kMaxMixSeconds`(0.25s)，
  不会把一秒钟的声音一口气灌进去。
- **没有声卡的机器也立得住。** 开不出设备就退到一个只数帧的 sink（`内核/audio/include/zlong/audio/
  null_sink.h`），画面照常，控制台说清楚「没有声卡 —— 画面照常，只是听不见」。`System::Mix` 本来在
  `audio_ == nullptr` 时是直接报错的，那个 sink 就是让工具在这里不倒的那个 seam。

### 为什么只在编辑的时候重新 `Load`

`System::Load` 会把整份场景重新上传（量过：0.07 毫秒），所以这个工具**每次改动都重新 `Load`** ——
和建模器一个做法。但声音那边有一个额外的约束：`SoundRenderer::Prepare` 原本会把每个 voice 的
**播放游标归零**。那样的话，拖一个声源会让它每一帧从头重启（拖动一帧一次 `Load`），根本没法边拖
边听。

所以 `Prepare` 改成了**同一段声音接着放，不从头来**：一个发射器如果还是放那一段（同一个声音、同一
个循环开关、同样的采样率和帧数），它的播放位置就**留着**（`引擎/src/sound.cpp` 的 `VoiceSignature`
和那段注释）。哪一段换了、或者增删让序号挪了，那一个才从头。判据是**指纹**而不是 `clip` 指针 ——
重新 Load 之后上一批的指针已经指到别人身上了。于是拖声源、改音量、改距离都是**平滑**的，
只有换了一段声音才重新开始。

## 这一版不做什么

写文档的人有责任说清楚哪里还没做。

- **音符格子没有缩放 / 横向滚动**（整遍铺满格子），也没有力度编辑、多选 / 复制粘贴 / 框选；吸附固定
  1/4 拍，关不掉。很长的曲子格子会很细。
- **音符是固定音高**（没有 per-note 滑音）；曲子也没有段落、重复记号之类"曲式"的东西 —— 一个
  `loop` 就是一个循环段，要两段就先拼成一段长的。
- **音效能做了，但没有"效果器"。** 合成（波形 + 音高 + 包络）在 `引擎/include/zlong/engine/synth.h`；
  混响、延迟、失真、滤波器栈都**不在这一层里**（只有一个单极点低通当代"颜色"）。混音那一侧的处理仍是
  既有的那几样：**增益**、**等功率声像**（一个角的余弦和正弦）、**线性衰减**（参考距离内满音量、最远
  距离外静音，中间一条直线）、**线性重采样**、**master**。想要一条效果链，那是往 `内核/audio` 加
  一层，是另一件事。
- **听者就是相机。** 引擎那条法的直接后果：**转视角 = 转头**，没有独立的编辑器相机。想要"看着一个
  固定的听者转"，要改 `SoundRenderer`（让它接一个听者，而不是拿 `scene.camera`）——记在这里。
- **没有波形 / 频谱视图。** 每帧要更新纹理就得每帧 `Load`，那会把声音一直重启（见上）。真要做，
  走**宿主自己在送出去的帧上叠加**（帧本来就是 RGBA），不改引擎 —— 也是另一件事。
- **读 `.scene` 只读声音那一半**，几何丢掉（见上）。
- **撤销栈 64 步**，每步是整串声源一份快照（PCM 是共享指针，所以一份快照很小）。
- **设备只在 Windows**（WASAPI）。别处自动落到那个只数帧的 sink。
