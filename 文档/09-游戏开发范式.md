# 游戏开发范式

> *「机器驱动你，不是你驱动机器。」*

这份文档管三件事：**游戏怎么写**、**打包器遵守什么**、**怎么起名字**。它们是同一件事的三面 ——
因为**一个游戏就是一个文件夹，一个文件夹就是一个程序，一个程序就是一个 exe**。这三句话定下来，
另外两件事就没有什么地方可以发挥的了。

---

## 一、范式的第一条：没有循环

**你写的东西里，一句 `while` 都没有。**

一个游戏 = 实现 `zlong::system::Platform` 的几个回调，再把这台机器**交给机器自己跑**：

```cpp
#include "zlong/engine/scene_file.h"
#include "zlong/system/system.h"

class MyGame final : public zlong::system::Platform {
    // 平台自己的活（收窗口消息）。**false = 平台没了 = 循环停。**
    bool Pump() override { return window_.Alive(); }

    // 画好的一帧：RGBA8，第一行在最上面。
    void Present(const std::uint8_t* rgba, std::uint32_t pitch,
                 std::uint32_t width, std::uint32_t height) override {
        window_.Blit(rgba, pitch, width, height);
    }

    // 每帧一次，在渲染之前。**在这儿收输入、动相机、改场景。**
    void OnFrame(zlong::engine::Scene& scene, double last_frame_seconds) override {
        board_.Advance(last_frame_seconds);
        board_.Draw(scene);                       // 把这一帧的样子写进场景
    }

    // 每块声音一次。不管声音就不用写这个。
    void OnMix(zlong::engine::Scene& scene, double seconds_mixed) override {}
};

int main() {
    zlong::system::System::Config config;
    config.width = 1280;
    config.height = 720;

    zlong::system::System machine(config);
    if (!machine.ok()) {
        std::fprintf(stderr, "%s\n", machine.error().c_str());   // 说不出来就不启动
        return 1;
    }

    MyGame game;
    machine.set_platform(&game);
    machine.Load(MyScene());
    machine.Run();                                // 循环在这儿，不在你这儿
    return 0;
}
```

### 为什么是反的

| 你以为你该管 | 实际上是谁管 |
|---|---|
| `while (running)` | `System::Run()` |
| 拿到 GPU、建交换链、每帧提交 | `System`（内部是 `gpu::Gpu` + Vulkan） |
| 申请显存、算帧率、记故障 | `System`（`frames()` / `gpu()` / `fault_log()`） |
| 音频节流、混音排期 | `System::Mix` |
| 什么时候退出 | `Pump()` 返回 false，或者窗口没了 |

**宿主"描述内容，不组装机器"** —— 这是 `宿主/render_scene/main.cpp` 开头那句注释，也是这一层存在
的全部理由。你要是自己 `new` 一个 GPU、自己开线程提交，那你是在重写 `System`，不是在写游戏。

### 没有循环也能跑

`Frame()` 画一帧、`Mix(seconds)` 混一块，两个都是**可以单独调**的：

```cpp
machine.Load(scene);
machine.Frame();          // 画一帧，画面在 machine.renderer() 里
WriteBmp(out, machine.renderer());      // 存成图
```

`宿主/render_scene` 就是这么干的 —— 它没有循环，也没有 `Platform`，它描述一个场景、画一张图、
写进文件。**做渲染回归、截图、批处理，走的就是这条路。**

## 二、第二条：场景是数据

`Scene` 是**纯数据**：相机、灯、网格、材质、节点树、声音、发射器。它不知道 GPU、不知道客人内存、
不知道设备。

```cpp
zlong::engine::Scene scene;
scene.camera.eye = {0.0f, 2.8f, 6.2f};
scene.meshes.push_back(zlong::engine::MakeBox());
scene.textures.push_back(zlong::engine::MakeCheckerTexture(64, 8));

zlong::engine::Light key;
key.direction = {0.45f, 0.80f, 0.40f};
scene.lights.push_back(key);

zlong::engine::Node tower;
tower.mesh = 1;                                  // 指向上面那个盒子
tower.transform = zlong::engine::RotationY(zlong::engine::Radians(35.0f));
tower.parent = -1;                               // 没有父节点 = 挂在世界里
scene.nodes.push_back(tower);
```

**加一样东西 = 加一条数据，不是加一段代码。** 一千个物体是 `push_back` 一千次，不是改一千处。

**帧是每帧现算的**：相机动了不用重新 `Load`，改 `scene.camera` 就行 —— 渲染器每帧从它现算矩阵。

### 所以关卡是文件

同一个场景能存成文本（`.scene`）：

```
camera 0 2.8 6.2   0 0.6 0
light 0.45 0.80 0.40   0.85 0.82 0.75
grid 1
box
node 0 -1   0 0 0   0 1 1
```

于是"关卡长什么样"是**数据**：能改、能进版本管理、能两个人各写一半、能不重编程序换一关。

**工具不该猜语言，关卡也不该藏在代码里。**

## 三、第三条：一个游戏就是一个文件夹

```
我的游戏/
    我的游戏.cpp           ← 入口。必须有 int main()
    棋盘.cpp
    规则.cpp
    关卡.scene            ← 不是源码的东西：原样拷到 exe 旁边
    棋子.bmp
```

| 没有 | 因为 |
|---|---|
| **没有构建脚本** | 不用 CMakeLists、不用 Makefile、不用 `.vcxproj` —— **文件夹就是清单** |
| **没有工程文件** | 不用配置"哪些文件属于这个程序" |
| **没有头文件目录约定** | 同目录的 `.cpp` 一起编，`#include "自己的头.h"` 直接写 |

**同目录的所有 `.cpp` 一起编。** 这条和"按 F5 跑当前文件"是同一句话 —— 按 F5 时，编辑器也是把
那个文件夹里所有的 `.cpp` 一起编的。**打包器编的东西和 F5 编的东西必须是同一套**，不然会出现
"按 F5 跑得好好的，打出来就缺符号"。

> 这条踩过坑：`宿主/xiangqi/` 有六个 `.cpp`，但项目说这个程序是**五个源文件 + 一个库**
> （`rules.cpp` 属于那个库）。打包器照着文件夹扫六个，当场撞出 26 个 `duplicate symbol`。
> 现在的规矩是"**打包编的东西和按 F5 编的是同一套**"。

---

## 四、第四条：只有 C++ 一条路

引擎是 C++，游戏就是 C++。**打包器不猜语言，也没有第二条会让人误会能走的路。**

> 这里曾经还认过 Python，而且认得很糟：它按"你现在打开的是哪个文件"猜语言 —— 在一个 C++ 游戏里
> 点开一个 `.py` 看一眼，整个游戏就改成按 Python 打；更荒唐的一次是拿 `编码器/` 自己（正好十三个
> `.py`）当成一个 Python 游戏去冻结。**那条路已经删掉了。**

---

## 五、第五条：数据放在 exe 旁边，路径写相对

```cpp
zlong::engine::Scene scene;
zlong::engine::LoadScene("关卡.scene", scene);    // 相对路径
```

打包时，文件夹里**不是源码的东西**（`.scene` / `.bmp` / `.model` / `.json`）**原样拷到 exe 旁边**，
不塞进 `依赖库/`。

因为程序里写的是相对路径。把文件挪到子目录里，那些路径全断。`依赖库/` 只放"程序之外、跑起来要有
的东西"（Qt、运行库），**不放游戏自己的资源**。

产物：

```
<游戏文件夹的上一级>/发行/<游戏名>/
    <游戏名>.exe        游戏的代码，编成一个 exe
    依赖库/             程序之外、跑起来要有的东西（通常几乎是空的）
    关卡.scene          游戏自己的数据，原样放在 exe 旁边
    棋子.bmp
```

按「打包游戏」（`Ctrl+Shift+B`）会问一个**游戏名**（默认是文件夹名）。

### 两条护栏

| 护栏 | 为什么 |
|---|---|
| **不能拿工作室自己的零件当游戏** | `编码器/`、`内核/`、`引擎/`、`宿主/`、`运行环境/` 这些是**做游戏用的东西**，不是游戏 |
| **产物不能落在游戏文件夹里面** | 打包第一步是清空输出目录 —— 落在里面就等于把游戏自己删了 |

两条都会在**输出面板里说清原因**，不是静默拒绝。

## 六、命名

### 一句话

**目录告诉人，文件告诉编译器；名字念得出来，就不用注释。**

### C++

| 什么 | 规矩 | 例 |
|---|---|---|
| 顶层目录 | **中文** —— 它是给人看的分类 | `内核/` `引擎/` `宿主/` `编码器/` `文档/` `工具链/` `运行环境/` `发行/` `依赖库/` |
| 内部目录 | **全 ASCII 小写** | `include/zlong/gpu/vulkan/` |
| 文件 | `snake_case` | `model_file.h` `vk_renderer.cpp` |
| 类型（`class` / `struct` / `enum`） | `PascalCase` | `MeshDescription` `RenderBackend` `WaitKind` |
| 函数 / 方法 | `PascalCase` | `MakeBox` `BakeMesh` `OnSvc` `Submit` |
| 成员变量 | `snake_case_`，**尾下划线** | `core_` `pending_interrupts_` `colour_view_` |
| 常量 | `k` + `PascalCase` | `kMaxLights` `kNoTexture` `kDescriptorAfBit` |
| 枚举值 | `PascalCase` | `WaitKind::Park` `Texture` |
| 命名空间 | `zlong::<层>` | `zlong::engine` `zlong::gpu::vulkan` |
| 宏 | `ZL_` + `SCREAMING_SNAKE` | `ZL_GPU_WITH_VULKAN` |

**为什么顶层目录用中文**：目录名是人读的，中文一眼就懂，而它从来不用出现在编译器参数里。
**为什么内部全 ASCII**：那些名字要走命令行、要进 `.obj`、要塞进别处的构建系统 ——
而**中文路径传不进命令行**（实测：clang 收到的是按 ANSI 代码页重读过的字节）。

### Python（编辑器这一半）

| 什么 | 规矩 | 例 |
|---|---|---|
| 模块 | `snake_case` | `viewport.py` `editor_host.py` |
| 函数 / 变量 | `snake_case` | `frame_at()` `held_modifiers` |
| 类 | `PascalCase` | `Viewport` `EditorWindow` |
| 私有 | `_` 打头 | `_on_view_key` `_MODEL_BUTTONS` |
| 模块级常量 | `_` 打头 + `UPPER_SNAKE` | `_MODE` `_EXE_EXCLUDES` |

### 一个游戏

| 什么 | 规矩 | 例 |
|---|---|---|
| 游戏文件夹 | 你自己起，**中文可以** | `我的游戏/` `宿主/xiangqi/` |
| 源文件 | 同上，`snake_case` 或者中文文件名都行 | `main.cpp` `规则.cpp` |
| 产物 | `<游戏名>.exe` + `依赖库/` | 跟着文件夹名 |

### 名字要是一句话

不用注释就能读懂的合成词，胜过一句注释。这条在能对外说的地方最要紧，比如**测试名**：

```cpp
culling_drops_the_winding_that_faces_away
```

它念出来就是它断言的事。**"这个测试是干什么的"不该要人点进去看。**

## 七、打包器的范式（一张表）

| 规矩 | 为什么 |
|---|---|
| **输入是"一个文件夹"** | 和 F5 同一条规矩，不另立一套 |
| **编的东西和 F5 编的是同一套** | 不然"跑得好好的，打出来缺符号" |
| **只有 C++ 一条路** | 工具不猜语言 |
| **数据原样放 exe 旁边** | 程序里是相对路径 |
| **产物不落进游戏文件夹** | 第一步会清空输出目录 |
| **拒绝工作室自己的零件** | 那不是游戏 |
| **先问名字，问到才动手** | 产物目录已经有东西时先问要不要覆盖 |

## 八、一份能跑的最小游戏

```cpp
// 我的游戏/我的游戏.cpp
#include <cstdio>
#include "zlong/engine/scene.h"
#include "zlong/engine/scene_file.h"
#include "zlong/system/system.h"

namespace {

zlong::engine::Scene BuiltIn() {
    zlong::engine::Scene scene;
    scene.camera.eye = {0.0f, 1.6f, 3.2f};
    scene.camera.target = {0.0f, 0.5f, 0.0f};
    scene.background = {0.05f, 0.06f, 0.10f, 1.0f};

    scene.meshes.push_back(zlong::engine::MakeGrid(1));
    scene.meshes.push_back(zlong::engine::MakeBox());

    zlong::engine::Light sun;
    sun.direction = {0.42f, 0.78f, 0.36f};
    scene.lights.push_back(sun);

    zlong::engine::Node box;
    box.mesh = 1;
    box.transform = zlong::engine::Translation(0.0f, 0.5f, 0.0f);
    scene.nodes.push_back(box);
    return scene;
}

class Simple final : public zlong::system::Platform {
public:
    bool Pump() override {
        if (frames_ > 300) return false;          // 300 帧之后自己退
        return true;
    }

    void OnFrame(zlong::engine::Scene& scene, double seconds) override {
        ++frames_;
        spin_ += seconds;
        scene.nodes[1].transform =
            zlong::engine::RotationY(static_cast<float>(spin_));
    }

    void Present(const std::uint8_t*, std::uint32_t, std::uint32_t, std::uint32_t) override {}

private:
    int frames_ = 0;
    double spin_ = 0.0;
};

}  // namespace

int main() {
    zlong::system::System::Config config;
    config.width = 800;
    config.height = 500;

    zlong::system::System machine(config);
    if (!machine.ok()) {
        std::fprintf(stderr, "起不来：%s\n", machine.error().c_str());
        return 1;
    }

    Simple game;
    machine.set_platform(&game);
    machine.Load(BuiltIn());
    machine.Run();

    std::printf("画了 %zu 帧，%zu 次提交，%zu 个 GPU 故障\n",
                machine.frames(), machine.draws(), machine.faults());
    return 0;
}
```

放在**一个空文件夹**里、按 F5 就能跑；「打包游戏」就能拿走。
