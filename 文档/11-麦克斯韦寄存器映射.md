# 麦克斯韦寄存器映射

把一台游戏机的 3D 引擎状态翻成 `render::DrawDesc`。这张表是 `蛟龙/` 里转换器的依据：
一边是寄存器，一边是 `内核/gpu` 的绘制描述，中间差的每一格都写在下面。

**为什么不能「结构体对结构体」**：对面**没有绘制描述这个概念**。它的 `Draw(bool is_indexed,
u32 instance_count)` 不带任何状态 —— 渲染器自己去读引擎寄存器。所以这张表是
**寄存器 → `DrawDesc`**，转换必须发生在对方渲染器的位置上，不是在什么接口上。

---

## 三件比任何一行都重要的事

**一、好几格不是寄存器直取。**

| `DrawDesc` 里 | 真实来源 | 为什么 |
|---|---|---|
| `color` / `depth`（渲染目标） | TIC / surface 描述符 | 渲染目标不在引擎状态里，是纹理层解析出来的 |
| `textures[]` | TIC / TSC 描述符 | 同上 |
| `constants[]` | 常量缓冲引擎接口 | 不在引擎状态里 |
| `vertex_shader` / `fragment_shader` | 程序地址寄存器 → 取字节码 → `shader::Module` | 这一格最重 |

**二、枚举有两套编码。** 引擎里 `ComparisonOp`、`Blend::Equation`、`Blend::Factor`、`StencilOp`
**每个都有 D3D 一套和 GL 一套**（`Less_D3D = 2` / `Less_GL = 0x201`…）。归一化必须同时认两套，
只认一套的转换器会在客体换一套的那天开始出错，而且不报错。

**三、视窗要推导，不能抄。** 引擎存的是 **scale/translate**，不是矩形：

```
GetX()      = max(0, translate_x − |scale_x|)
GetY()      = max(0, translate_y − |scale_y|)
GetWidth()  = translate_x + |scale_x| − GetX()
GetHeight() = translate_y + |scale_y| − GetY()
```

把 `scale_x` 当宽度抄进去，画面会在每一帧都错，而且错得「看起来只是没对齐」。

## 逐字段

| `DrawDesc` 字段 | 来源 | 注意 |
|---|---|---|
| `viewport.x/y/width/height` | `viewport_transform` 的 scale/translate | **推导**，见上 |
| `viewport.min_depth` / `max_depth` | `viewport.depth_range_near/far` | **直接取**。裁剪约定位（`view_clip_control.depth_0_to_1`）是顶点着色器输出那一层的事，不是这一层 —— 它决定的是深度怎么写出去，不是视窗范围是什么 |
| `scissor` | `scissor_test.{min_x,max_x,min_y,max_y}` | 转 `Rect{x,y,width,height}`；**1×1 且 min==max 是「禁用」约定** |
| `raster.cull` | `d3d_cull_mode` | `FrontAndBack` 这一档本层没有，见下 |
| `raster.front_face` | `front_face`：`ClockWise=0x900` / `CounterClockWise=0x901` | 绕向定义跨图形 API 不一致，要对齐 |
| `raster.scissor_enable` | `scissor_test.enable` | 一比一 |
| `depth_state.test_enable` | `depth_test_enable`（0x12CC） | 一比一 |
| `depth_state.write_enable` | `depth_write_enabled`（0x12E8） | 一比一 |
| `depth_state.compare` | `depth_test_func`（0x130C） | 归一化双编码 |
| `blend.enable` | `blend.enable[target]`（**每目标一个**）与 `blend_per_target_enabled`（0x12E4） | 不是单一寄存器 |
| `blend.src/dst_color/color_op` | `blend_per_target[target]`（0x1E00）或全局 `blend` | 由 `blend_per_target_enabled` 择一 |
| `blend.src/dst_alpha/alpha_op` | 同上，看 `separate_alpha` | 不分时 alpha 与 color 同源 |
| `blend.write_mask` | `color_mask`：R(0) G(4) B(8) A(12) | **压成 nibble**：`(R<<0)\|(G<<1)\|(B<<2)\|(A<<3)` |
| `clear.*` | `clear_control` + `clear_rect` + 清值 | `use_clear_rect` / `use_scissor` 决定用哪个矩形 |
| `topology` | `vertex_array.topology` / `index_buffer_small.topology` / `draw.topology` | **三个来源**，由拓扑控制位择一 |
| `vertex_count` / `first_vertex` | `vertex_array_instance_first.{start,count}` | start → first，count → vertex_count |
| `index_count` / `first_index` | `index_buffer.{count,first}` | `IndexStart()` 已把 first 算进字节偏移 |
| `index_type` | `index_buffer.format` | `UnsignedByte` 本层没有，见下 |
| `index` | `index_buffer`（start/limit 各高 32 + 低 32 拼）或 `index_buffer_small` | **是 GPU 地址，要过 `GpuAddressSpace::Resolve`** |
| `vertex_buffers[]` | `vertex_stream[]`（地址 / 限制 / 步长 / divisor） | 同上，GPU 地址 |
| `attributes[]` | `vertex_attrib_format[]` + `vertex_attribute{buffer,constant,offset,size,type,bgra}` | **location 不是槽位号** —— 由着色器输入决定，要按着色器输入映射 |

## 形状不够的

不是「还没做」，是**枚举现在就装不下**：

| 枚举 | 本层有 | 引擎还有 |
|---|---|---|
| `PrimitiveTopology` | Points / Lines / Triangles / TriangleStrip | +LineLoop、LineStrip、TriangleFan、Quads、QuadStrip、Polygon、LinesAdjacency、LineStripAdjacency、TrianglesAdjacency、TriangleStripAdjacency、**Patches** |
| `BlendFactor` | 10 个 | +SourceAlphaSaturate、BothSourceAlpha、OneMinusBothSourceAlpha、**BlendFactor / OneMinusBlendFactor**、**Source1Color/Alpha（双源混合）**、ConstantColor / ConstantAlpha |
| `IndexType` | None / UInt16 / UInt32 | +**UnsignedByte** |
| 顶点属性格式 | `SurfaceFormat` 13 个值，而且**是给 surface 用的** | 引擎有 19 种 size × 7 种 type。能落到 `SurfaceFormat` 上的只有 `R32G32B32A32_FLOAT`、`R32G32_FLOAT`、`R8G8B8A8_UNORM`、`B8G8R8A8_UNORM` 四对，其余全部**拒绝** |

对得上的两组：`CompareOp`（8 档）与 `BlendOp`（Add / Subtract / ReverseSubtract / Min / Max）
**和引擎完全一致**。

**剔除方向不是一比一。** 引擎的 `D3DCullMode` 说的是「剔除哪种绕向的面」（`CW` / `CCW`），
本层的 `CullMode` 说的是「剔除哪一面」（`Front` / `Back`）。**两者由绕向设定连起来**：

```
剔除的是正面  ⟺  (cull == CW) == (front_face == ClockWise)
```

所以同一份寄存器状态，绕向一变，`Front`/`Back` 就得跟着翻。抄成一比一会让一半的模型内外面反着。

---

## `DrawDesc` 装不下的

| 引擎有 | 本层 |
|---|---|
| 深度偏移（`depth_bias_control`，0x1110） | `RasterState` 里没有位置 |
| 完整模板操作（`stencil_op`） | `DepthState` 只有比较，没有模板 |
| 多渲染目标（`rt_control` 最多 8 个，每个独立混合） | 只有一个 `blend` 和一个 `color` |

---

## 有意留下的空缺

| 空缺 | 在哪 |
|---|---|
| 转换器**只认一个颜色目标**：多目标的画会被拒，不是被悄悄画成一个 | `蛟龙/` 转换器 |
| `UnsignedByte` 索引**没有对应档**，拒绝 | 同上 |
| 十九种顶点 size 里只有四种能落到 `SurfaceFormat`，其余**拒绝整次绘制** | 同上 |
| 着色器那两格**只填指针，不做编译** —— 字节码到 `shader::Module` 是另一个动作 | 同上 |
| 深度偏移与模板**丢掉**：`DrawDesc` 没有位置，转了也无处放。画出来的结果在用到它们的场景里是错的 | 本表「装不下的」一节 |
